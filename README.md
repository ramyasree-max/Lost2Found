# lost2found - Campus Lost and Found Portal (Sai University)

A responsive, database-driven full-stack web application developed for the **Web Technology and Internet Programming** individual project (Academic Year 2026-2027).

## Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript ES6+, FontAwesome Icons
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose ODM)
- **API Testing:** Postman
- **Version Control:** Git & GitHub

## Running Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the application:
   ```bash
   node server.js
   ```
3. Access in browser: `http://localhost:5000`
